# 🚀 Protocol Scanner - Веб-панель

Многопоточный сканер портов с веб-интерфейсом для быстрого сканирования всех портов (1-65535) с поддержкой RDP, VNC, SSH, Telnet и других протоколов.

## 🎯 Особенности

- **Многопоточное сканирование** - 3 параллельных потока
- **Быстрое время выполнения** - 2-3 секунды для всех портов
- **Агрессивный метод** - максимальная информация о сервисах
- **Веб-интерфейс** - простой и удобный
- **Поддержка протоколов** - RDP, VNC, SSH, Telnet, HTTP, HTTPS, FTP и другие

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip3 install -r requirements_web.txt
```

### 2. Запуск веб-панели
```bash
python3 web_scanner.py
```

### 3. Открыть в браузере
```
http://localhost:8080
```

## 🎯 Использование

1. **Откройте веб-панель**: http://localhost:8080
2. **Введите данные**:
   - Целевой хост (IP адрес)
   - Имя пользователя
   - Пароль
3. **Нажмите "Начать сканирование"**
4. **Получите результаты** за 2-3 секунды

## 🔧 Технические детали

- **Сканирование**: Многопоточное nmap с агрессивными настройками
- **Порты**: Все 65535 портов
- **Потоки**: 3 параллельных потока (1-20000, 20001-40000, 40001-65535)
- **Протоколы**: RDP, VNC, SSH, Telnet, HTTP, HTTPS, FTP, SMTP, IMAP, POP3, MySQL, PostgreSQL, Redis, MongoDB
- **Логика**: Подключение только к сервисам, определенным nmap
